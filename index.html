folio

A blazing-fast, magazine-styled static book reader for Markdown content hosted on GitHub Pages

folio transforms Markdown documents into a magazine-styled reading experience with zero build steps. Write in pure Markdown, host freely on GitHub Pages, and provide your readers with elegant serif typography, three themes (Light, Dark, AMOLED), fluid keyboard and swipe navigation, reading time estimates, and nested volume/arc organization.
